IMPORTANT NOTES:

1. GEE_SERVICE_ACCOUNT_JSON:
   - Get your service account JSON from Google Cloud Console
   - Open the JSON file in a text editor
   - Copy the ENTIRE content (starts with { ends with })
   - Replace YOUR_SERVICE_ACCOUNT_JSON_HERE with the actual JSON
   - Should look like: {"type":"service_account","project_id":"..."}

2. GEE_PROJECT:
   - Current value: arctic-hybrid-462806-c9
   - Change this if you want to use a different Google Cloud project

3. RR_HOST:
   - MUST be 0.0.0.0 for Railway (NOT 127.0.0.1)
   - This is already set correctly above

4. CORS_ORIGINS:
   - Currently set to * (allows all domains)
   - For production, change to your domain:
     CORS_ORIGINS=https://your-app.railway.app

════════════════════════════════════════════════════════════════════════
  HOW TO GET SERVICE ACCOUNT JSON
════════════════════════════════════════════════════════════════════════

Step 1: Create Service Account
   1. Go to: https://console.cloud.google.com
   2. Select project: arctic-hybrid-462806-c9 (or your project)
   3. IAM & Admin → Service Accounts
   4. CREATE SERVICE ACCOUNT
   5. Name: railway-road-roughness
   6. CREATE AND CONTINUE → DONE

Step 2: Create Key
   1. Click on the service account
   2. Keys tab → ADD KEY → Create new key
   3. Choose: JSON
   4. CREATE (file downloads)

Step 3: Register with Earth Engine
   1. Go to: https://code.earthengine.google.com
   2. Register the service account email (from the JSON file)

Step 4: Copy JSON
   1. Open the downloaded JSON file
   2. Select ALL content (Ctrl+A or Cmd+A)
   3. Copy (Ctrl+C or Cmd+C)
   4. Paste to replace YOUR_SERVICE_ACCOUNT_JSON_HERE above
