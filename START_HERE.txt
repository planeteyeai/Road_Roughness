🚀 QUICK START (3 STEPS)
═══════════════════════════════════════════════════════════════════════

STEP 1: Get Earth Engine Service Account
   • Go to: https://console.cloud.google.com
   • Create service account → Download JSON key
   • Register at: https://code.earthengine.google.com

STEP 2: Push to GitHub
   git add .
   git commit -m "Deploy to Railway"
   git push origin main

STEP 3: Deploy on Railway
   • Go to: https://railway.app
   • New Project → Deploy from GitHub repo
   • Set environment variables (see below)
   • Done! App is live in 3-4 minutes

═══════════════════════════════════════════════════════════════════════

🔑 REQUIRED ENVIRONMENT VARIABLES
═══════════════════════════════════════════════════════════════════════

Set these in Railway dashboard:

GEE_PROJECT=your-gee-project-id
GEE_SERVICE_ACCOUNT_JSON={"type":"service_account",...}
RR_HOST=0.0.0.0
RR_PORT=8000
CORS_ORIGINS=*
SERVE_FRONTEND=true

🐛 COMMON ISSUES
═══════════════════════════════════════════════════════════════════════

Build Fails:
→ Ensure Dockerfile is in repository root
→ All files committed to Git

App Crashes:
→ Check GEE_SERVICE_ACCOUNT_JSON is complete
→ Verify GEE_PROJECT is correct

Earth Engine Error:
→ Register service account at code.earthengine.google.com
→ Enable Earth Engine API in Google Cloud Console

Storage Not Persisting:
→ Add persistent volume in Railway
→ Mount at: /app/road_roughness/backend/storage

DETAILED TROUBLESHOOTING: See README_RAILWAY.md
